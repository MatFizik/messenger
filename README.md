# Messenger

Flutter messenger app built with Firebase and BLoC.

## Overview

This pet project demonstrates a messenger-style mobile UI with authentication, chat screens, theming, and animated interactions.

## Features

- Firebase Authentication flow
- Chat list and chat screen
- Cloud Firestore integration
- Light and dark themes
- Animated splash and UI effects
- Message interaction feedback and haptics

## Stack

- Flutter
- Dart
- Firebase Auth
- Cloud Firestore
- BLoC / flutter_bloc
- Lottie
- toastification
- vibration
